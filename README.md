# Расписание уроков и подготовка вещей (School) — Android App (v1.4)

Современное мобильное Android-приложение на Jetpack Compose для школьного расписания уроков и подготовки вещей в рюкзак.

Поддерживает прямую **P2P Wi-Fi синхронизацию** между устройствами (телефон родителя ↔ планшет ребёнка) без внешних облаков или серверов.

---

## 📱 Ключевые возможности

### 1. Просмотр расписания для ребёнка (Режим «Планшет Алисы»)
- Режим предназначен специально для планшета: ребёнок видит расписание и чек-лист рюкзака.
- По умолчанию при запуске приложения расписание сразу открывается **на завтра** — чтобы ребёнок с вечера видел нужные уроки и спокойно собирал рюкзак.
- В настройках планшета нет никаких паролей и пин-кодов — доступно только изменение сетевого имени устройства.
- **3 удобных режима отображения:**
  - **День:** фокус на выбранном дне с отметками «сегодня» и «на завтра».
  - **Неделя:** обзор всех 7 дней недели с быстрым переходом к конкретному дню в 1 клик.
  - **Месяц:** интерактивная календарная сетка с точками-индикаторами учебных дней.
- **Интерактивный чек-лист рюкзака («Что взять»):**
  - Раскрывающиеся карточки уроков с динамическим счетчиком готовности (например, `3/3`).
  - Вычёркивание собранных вещей по тапу на чекбокс.
- **Push-уведомления:** планшет мгновенно сообщает ребёнку, если родитель изменил расписание.
- **Полный офлайн:** расписание кэшируется в локальном хранилище (DataStore) и доступно даже без сети.

### 2. Редактор и управление (Режим «Сервер / Папа»)
- **Встроенный редактор расписания:**
  - Добавление и удаление учебных дней.
  - Добавление, редактирование и удаление уроков.
- **Умный барабанный выбор времени (WheelNumberPicker):**
  - **Автозаполнение по шаблону звонков:** при вводе номера урока (1..8) время начала и конца выставляется автоматически:
    - 1 урок: 08:30–09:05
    - 2 урок: 09:25–10:00 (перемена 20 мин)
    - 3 урок: 10:20–10:55 (перемена 20 мин)
    - 4 урок: 11:05–11:40 (перемена 10 мин)
    - 5 урок: 11:50–12:25 (перемена 10 мин)
    - 6 урок: 12:35–13:10 (перемена 10 мин)
    - 7 урок: 13:20–13:55 (перемена 10 мин)
    - 8 урок: 14:05–14:40 (перемена 10 мин)
  - Инерционный скролл с привязкой (snap), тактильным откликом (haptic feedback) и защитой от дрейфа значений.
  - Возможность ручной корректировки времени с индикатором длительности урока и кнопкой быстрого возврата к шаблону.
- **Адаптация под экранную клавиатуру:** окно редактирования автоматически поджимается вверх (IME padding), исключая перекрытие поля ввода списка вещей.

### 3. Автоматическая синхронизация по Wi-Fi
- Не требует ручного ввода IP-адресов.
- Телефон папы периодически анонсирует своё присутствие в локальной подсети по UDP Broadcast (порт `8888`).
- Планшет дочки автоматически обнаруживает телефон, подключается к встроенному HTTP-серверу Ktor (порт `8080`) и скачивает актуальное расписание при изменении версии.
- Кнопка ручной синхронизации в статус-баре для немедленной проверки связи.

### 4. Безопасность и режимы доступа (Концепция «Планшет Алисы» / «Телефон папы»)
- **Планшет Алисы (клиент):** на планшете отсутствуют любые пин-коды и пароли. Ребёнок может менять только имя устройства.
- **Телефон папы (сервер):** переход на вкладку папы защищён мастер-паролем (`1234` по умолчанию).
- **Неограниченный режим:** после ввода пароля уроки и дни создаются и редактируются напрямую без повторных запросов PIN-кодов. Сменить пароль можно на вкладке папы в любой момент.

## 🛠 Стек технологий

- **Язык:** Kotlin 2.2.10
- **UI:** Jetpack Compose (BOM 2024.09.03), Material 3
- **Архитектура:** Clean Architecture / MVVM, Single Activity, StateFlow, Coroutines
- **Сеть и P2P:**
  - Ktor Client 2.3.12 (OkHttp engine)
  - Встроенный Ktor Server 2.3.12 (CIO engine)
  - UDP DatagramSocket с автоматическим получением broadcast-маски подсети
- **Хранилище данных:** Jetpack Preferences DataStore 1.1.1, kotlinx.serialization
- **Требования:** `minSdk 26` (Android 8.0+), `targetSdk 34` / `compileSdk 34`

## 🚀 Сборка и запуск

1. Откройте директорию проекта в **Android Studio Ladybug (2024.2+)** или новее.
2. Дождитесь автоматической синхронизации Gradle.
3. Запустите проект на устройстве или эмуляторе (`Shift + F10` или кнопка ▶ Run 'app').
4. Сборка оптимизированного APK:
   `Build → Generate Signed Bundle / APK → APK → release`

## 📂 Структура проекта

```
app/src/main/
├── AndroidManifest.xml          — разрешения сети, foreground-сервиса и объявление активности
└── kotlin/com/schedule/app/
    ├── MainActivity.kt          — точка входа, инициализация навигации (NavHost)

    │   │   ├── ScheduleServer.kt— встроенный Ktor HTTP сервер на порту 8080

        │   ├── MainScreen.kt    — главный экран (День / Неделя / Месяц, чек-листы)
        │   ├── EditScheduleScreen.kt — редактор расписания, барабан времени, шаблон звонков
        │   └── SettingsScreen.kt— выбор роли (Папа / Дочка), имя устройства, PIN
        └── theme/               — дизайн-система: цвета, шрифты, формы
```
