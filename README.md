## 🌟 Ключевые возможности

### 1. Интерактивный сбор рюкзака («Что взять») с привязкой к датам
- **Строгая изоляция по календарным датам (`LocalDate`):** если ребёнок с вечера отмечает собранные вещи на завтра, отметки сохраняются исключительно за этой датой (`YYYY-MM-DD`). Во вторник следующей недели список будет чистым!
- **Динамический индикатор прогресса:** наглядная карточка с процентом готовности (`100% Готово ✓`), подсчётом оставшихся вещей и анимированным прогресс-баром.
- **Безопасный сброс отметок:** возможность очистить отметки текущего дня с подтверждением в диалоге.
- **Персистентность:** все отметки сохраняются на диске устройства через Preferences DataStore и не теряются при закрытии или перезагрузке.

### 2. 3 режима просмотра расписания
- **День:** детальный фокус на выбранной дате с плашками «Сегодня», «На завтра», «Вчера». Сквозные стрелки `<` и `>` позволяют непрерывно листать дни вперед и назад без ограничений недели или месяца.
- **Неделя:** полный обзор 7 дней (Пн–Вс) с количеством уроков и быстрым переходом к любому дню в 1 клик.
- **Месяц:** интерактивный календарь с точками учебных дней и подсветкой выбранной даты. Нажатие на любое число (например, 28-е) открывает именно выбранную дату и её уроки.

### 3. Двойная синхронизация (Облако + Локальная сеть)
- **Облачная синхронизация (CloudSync):** расписание передаётся через защищённое облако по коду семьи (по умолчанию `Алиса-2026`). Телефон родителя и планшет ребёнка всегда синхронизированы, даже находясь в разных местах и на мобильном интернете.
- **Локальный P2P Wi-Fi резерв:** встроенный Ktor-сервер и UDP-обнаружение в домашней сети без обращения к интернету.

### 4. Экспорт и импорт в Microsoft Excel (.xlsx / .csv)
- Полная интеграция с электронными таблицами Excel: возможность скачать готовый шаблон, отредактировать расписание на компьютере и импортировать в приложение в 1 клик.
- Экспорт расписания в Excel-файл для резервного копирования или отправки в мессенджеры.

### 5. Удобный редактор уроков (Режим «Родитель»)
- **Автозаполнение звонков (1..8 урок):** стандартное расписание уроков и перемен (20 мин / 10 мин) выставляется автоматически.
- **Защита от клавиатуры:** модальное окно адаптируется под экранную клавиатуру, предотвращая перекрытие полей ввода.
- **Мастер-пароль:** защита редактора от случайных правок ребёнком.

### 6. Автоматические обновления через GitHub Releases
- Приложение самостоятельно проверяет наличие обновлений в этом репозитории через быстрый CDN Fastly (`raw.githubusercontent.com`).
- Скачивание APK происходит напрямую из постоянного хранилища **GitHub Releases** с отображением шкалы прогресса и безопасной установкой.

## 🛠 Стек технологий

- **Язык:** Kotlin 2.2.10
- **UI:** Jetpack Compose (BOM 2024.09.03), Material 3, dynamic theme (Dark / Light)
- **Архитектура:** Clean Architecture / MVVM, Single Activity, StateFlow, Coroutines
- **Сеть:** Ktor Client & Server 2.3.12 (OkHttp / CIO)
- **Хранилище:** Jetpack Preferences DataStore 1.1.1, kotlinx.serialization
- **Работа с Excel:** Apache POI (POI-OOXML)
- **Требования:** Android 8.0+ (`minSdk 26`, `targetSdk 34`)
